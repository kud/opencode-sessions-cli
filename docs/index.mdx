---

opencode ink is a small Ink TUI for people who run several [opencode](https://opencode.ai) servers at once. It gathers their sessions into one list, hands the terminal to `opencode attach` when you pick one, and can stop the headless instances you no longer need. It installs as `opencode-ink` and the short alias `ocs`.

It is not on npm yet, so it is installed from source for now; the README has the steps.
